# Django Fruit App

A full-stack learning project for Developer Akademie.

## Tech Stack

- Python
- Django
- HTML
- JavaScript
- REST-style JSON endpoint

## Project Structure

- `backend/` — Django project and fruit API
- `frontend/` — HTML and JavaScript frontend

## Requirements

1. Create a Django project named `core`.
2. Create a Django app named `fruit_app`.
3. Implement a `send_fruits` view returning five fruits.
4. Expose the data at `/fruits/`.
5. Configure CORS.
6. Fetch the fruit data from the frontend.
7. Render the fruits as an HTML list.
